# AI Developer Agent 1.5.191

Локальный ИИ-агент для Windows: чат с моделью (Ollama, облачные API, G4F), работа с файлами
и терминалом, git/GitHub, браузер, деплой и Yandex Cloud, мобильный доступ с телефона,
почта, хранилище паролей. Данные и ключи остаются на вашем ПК.

Это первый выпуск после `v1.0.1` — в него вошли все версии 1.5.x. Ниже — то, ради чего
выпуск делался сейчас, плюс две вещи, о которых стоит знать до установки.

## Что нового в 1.5.191

**Мобильный доступ теперь по TLS.** Страница телефона уезжала по открытому `http`, и её
мог отдать кто угодно из той же сети — подменённая страница забирала сеанс устройства.
Теперь мост поднимается по `https` с самоподписанным сертификатом, а канал телефона идёт
как `wss`. Сертификат выпускается один раз, лежит рядом с настройками приложения, при
смене сети пересоздаётся сам.

- телефон при первом входе один раз покажет предупреждение о сертификате — это ожидаемо:
  «Дополнительно» → «Перейти на сайт»; сертификат можно внести в доверенные, и тогда
  предупреждения не будет;
- если сертификат не удалось выпустить, доступ остаётся, но панель настроек прямо
  говорит, что шифрования нет;
- выключателя шифрования в настройках нет намеренно — его выключил бы тот, кто уже в сети.

**Обновления кода подписываются.** Раньше целостность набора кода держалась на хеше из
манифеста, а манифест лежит рядом с набором — подмена не ловилась. Теперь набор несёт
подпись, и она проверяется до распаковки. Ключ подписи создаётся вами одной командой
(`npm run ota:key`), закрытая часть остаётся на вашем ПК и в репозиторий не попадает.
Пока ключ не создан, панель «Обновление кода» предупреждает, что подпись не настроена.

**Плюс то, что вошло в 1.5.2–1.5.190:** Electron 44, обновлённый сборщик, безопасность
IPC (телефону не уходят значения секретов, у разрушительных команд проверка отправителя,
у моста список разрешённого вместо одного запрета, вход по одноразовому коду вместо PIN
в ссылке, проверка адресов перед запросом), а также вся работа 1.5.x над агентом —
Yandex Cloud, деплой, почта, пароли сайтов, миссии, память диалогов, ускорение и разбор
ядра на модули. Подробности — в `AGENT-NOTES.md` в репозитории.

## До установки

- **Установщик без подписи кода** (сертификата подписи у проекта нет): Windows покажет
  «неизвестный издатель», SmartScreen может требовать «Подробнее» → «Выполнить в любом
  случае». Это ожидаемо и не признак подменённого файла — целостность файла проверяется
  по `sha512` в `latest.yml` при автообновлении.
- **Обновление у установленных копий** приходит по каналу GitHub: проверка раз в час или
  сразу после перезапуска. Обновление с `1.0.1` на `1.5.191` — крупное, приложение после
  установки стоит запустить, чтобы оно дописало свои файлы состояния.

## Файлы

| Файл | Что это |
|---|---|
| `ai_agent-1.5.191-x64.exe` | установщик (рекомендуемый) |
| `latest.yml` | описание обновления для автообновления |
| `ai_agent-1.5.191-x64.exe.blockmap` | обновление по частям, а не целиком |

Портативная сборка и zip собираются здесь же, но в релиз выкладывается установщик —
именно его ждёт канал автообновления.
