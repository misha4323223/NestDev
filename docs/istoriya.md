Главные правила API, без которых здесь всё разваливается: **домены сертификата изменить нельзя** (другой набор доменов — только новый сертификат), содержимое PEM меняется только у загруженного, маску `*.example.com` файлом на сайте подтвердить нельзя — только DNS-записью (и это отбивается ДО запроса), **запись подтверждения ровно одна** (CNAME лучше TXT: подтверждается один раз, дальше продления идут сами), сертификат и ресурс обязаны лежать в ОДНОМ каталоге, `cname` ресурса задаётся один раз и навсегда, у бакета-источника обязателен свой заголовок Host (иначе бакет отвечает CDN-серверам 404 — та самая «CDN настроен, а сайта нет»), группа источников правится запросом БЕЗ id в пути (id в теле, поле `groupName`), список источников заменяется целиком, очистка кэша: пустой список значит «всё», не больше 10 путей за запрос и один в минуту, звёздочка только в конце пути; изменения в CDN применяются до 15 минут. По ходу вскрылись и закреплены тестом три вещи: заголовок Host источника и адрес источника считаются ОДНИМ выражением (иначе у «просто бакета» CDN уходил к нему с сайтовым именем и получал 404), «облако ответило, что ресурс создан» ещё не значит, что сертификат привязался (ресурс перечитывается, и модуль говорит честно), а id выпущенного сертификата приходит в ответе ОПЕРАЦИИ, не в теле запроса. Порядок шагов не сокращён: пока домен не подтверждён, HTTPS не работает. Баланс — это не расход: минус и ноль названы прямо, потому что это единственный честный сигнал «облако скоро остановит ресурсы»; порог-бюджет — предупреждение, а не счёт (и создать его по API нельзя без id пользователя для уведомлений — отправляем в консоль, а не угадываем). Хвосты остаются видны, даже когда биллинг недоступен: они читаются правами каталога. Главное правило, без которого здесь всё разваливается: **у функции нет кода — код живёт в ВЕРСИИ**, а по умолчанию отвечает САМАЯ НОВАЯ версия (виртуальный тег `$latest`), поэтому постоянную ссылку даёт только тег (`v1`, `prod`), а выкатка выкатывает версию списком версий, архивом с ПК, копией прежней версии или архивом из бакета. Тело создания версии сверяется целиком (память — БАЙТАМИ строкой кратно 128 МБ, время — строкой секунд `30s`, тег — списком, источник кода ровно один из трёх), язык проверяется по ЖИВОМУ списку `/functions/v1/runtimes` (придуманный «node20» отбивается с похожими вариантами), а **вызов идёт на публичный адрес функции** и возвращает ответ чужого кода — JSON, текст или пустоту; 403 объясняется ролью `serverless.functions.invoker`, 504 — «не успела, смотри логи». Публичность — это роль `allUsers`, а не флаг, и привязки после записи ПЕРЕЧИТЫВАЮТСЯ; удаление функции забирает все версии и теги и сначала их называет, а последнюю версию удалить нельзя вовсе.
