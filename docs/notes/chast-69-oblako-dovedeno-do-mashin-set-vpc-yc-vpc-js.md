## Часть 69: облако доведено до машин — сеть VPC (`yc-vpc.js`) и Compute (`yc-compute.js`)

**Зачем.** Облако умело создавать «полки» (базы, бакеты, контейнеры), но не то, ради чего они нужны:
сеть и машину. Без подсети машина не встаёт, без группы безопасности — открыта всему интернету, а без
статического адреса её публичный IP меняется после перезагрузки. Путь «свой сервер» человек проходил руками
в чужой консоли, а модель могла только посмотреть, что уже есть.

**Что сделано.**
- `src/yc-vpc.js` — подсеть, группа безопасности и статический адрес модулем (чистый Node, без Electron).
  Правило входа без источника не создаётся; при правке группы уходит СПИСОК правил целиком, без `id` (сервис
  считает id своим) и без потери предопределённых правил; удаление несуществующего правила ловится ДО записи.
  Свободный диапазон для новой подсети подсказывается рядом с занятыми, а не первым из головы.
- `src/yc-compute.js` — машины: список и карточка, наборы (`micro`/`small`/`medium`/`full`), создание, питание,
  удаление, снимки, чистка снимков, восстановление диска, serial-консоль и метрики.
- Ключевые решения, которые нельзя терять при правке: зона машины берётся ИЗ ПОДСЕТИ (иначе облако отбивает
  `subnet is in a different zone`); память и размер диска уходят БАЙТАМИ строкой; публичного адреса нет без
  явной просьбы; serial-консоль включается метаданными ТОЛЬКО при создании; удаление машины не забирает
  диски с `autoDelete=false` — оставшиеся платные диски называются прямо; снимок предлагается до удаления.
- Стоимость машин — в `src/yc-costs.js` по опубликованным тарифам (уровни производительности 20/50/100%, диски,
  публичный адрес, снимки): цена есть, выдуманных чисел нет.
- Наборы: `test/yc-vpc.test.js` (24) и `test/yc-compute.test.js` (27). Оба работают на НАСТОЯЩЕМ модуле против
  локального HTTP-сервера с настоящей машиной состояний (штатный хук `AI_AGENT_YC_BASE`), проверяют тела
  запросов целиком и держат негативные контроли «облако ответило „сделано“, а ничего не сделало».
- Проводка: каналы `yc:vpc` и `yc:compute`, мост окна, схемы, группа «облако», промпт, права (`cloud.read`,
  а создание/питание/удаление — внутри инструментов по чекбоксам `ycAllowAgent*`) и справочник `yc.md`.

**Грабли.** Сборка модуля машин должна отдавать наружу `PRESETS`/`PRESET_KEYS` — их читают инструмент агента
и канал панели; без этого `action presets` падал на чтении `coreFraction` у `undefined`. Проверяется набором.
