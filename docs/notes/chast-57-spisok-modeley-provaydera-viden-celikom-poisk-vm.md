## Часть 57: список моделей провайдера виден ЦЕЛИКОМ — поиск вместо обрезки

**Зачем.** При подключении провайдера приложение показывало лишь часть моделей: попап в шапке —
первые 30, подсказки в настройках — первые 12. У OpenRouter моделей сотни, и найти нужную было
нельзя (выглядело так, будто «показаны только бесплатные»). Причина была не в загрузке —
`listModels` отдаёт весь список с `/models`, — а в жёсткой обрезке при ПОКАЗЕ.

**Что сделано.** Обрезки убраны, вместо них — поиск:
- попап модели (`src/renderer/model-popup.js` + `#mp-search` в `index.html`): строка поиска над
  списком фильтрует его на лету, рисуется ВЕСЬ список, пустой результат объясняется словами;
- настройки (`src/renderer/settings-panel.js` `renderModelHints` + `#model-search` в
  `index.html`, проводка в `app.js`): весь список отдаётся КОМПАКТНО — выпадающим списком
  (`.model-select`) вместо облака кнопок: при сотнях моделей облако занимало весь экран
  настроек, а список берёт одну строку. Поиск сужает варианты и пишет «Найдено X из Y», выбор
  вставляет модель в поле провайдера (включая маршрут G4F «Провайдер:»). У панели появился
  `refilterModelHints`.

**Проверки.** `test/model-popup.test.js`: проверка «список показан целиком» (45 из 45 вместо 30).
Новый тест поиска: сужение по подстроке, объяснение пустого результата, сброс поиска возвращает
весь список. `npm test` — 76 наборов, 0 падений.
