**Три неверные пробы (мои, не инструмента).** (1) id миссии читался шаблоном `[a-z0-9-]+`, а он
кончается кириллическим слогом из цели (`20260922-1132-разобрать-заявки`) — теперь `[^\s]+`.
(2) Проба давала один «живой» объект вместо двух разных форм (`deps.live` — метод-доступор,
`live` — сам отправитель); событие уходило в никуда, и это прятал `try/catch` внутри `notifyMission`.
(3) Повторное закрытие проверялось при ВТОРОЙ незакрытой миссии — и прогон честно брался за неё
(`missionOfRun` → активная); «уже закрыта» проверяется там, где незакрытых не осталось.

**Контроли.** (A) `missionOfRun` перестаёт смотреть на миссию прогона — ловит НАБОР, и это ровно
