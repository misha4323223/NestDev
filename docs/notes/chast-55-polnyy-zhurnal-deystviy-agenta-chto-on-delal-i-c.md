## Часть 55: полный журнал действий агента — что он делал и что получил (для продакшена)

**Зачем.** В собранном приложении нет терминала, и `console.log` главного процесса никуда не виден.
Панель «Консоль» показывает вывод агента, пока открыто окно; после перезапуска и на чужой машине
от неё ничего не остаётся. Журнал действий (`audit.log`) пишет ТОЛЬКО опасное и подтверждённое —
«агент сделал не то» по нему не разобрать. Это не наша выдумка: так делает любой продакшен — пишет
лог в файл, потому что UI живёт только пока открыт.

**Что сделано.** Новый модуль `src/agent-log.js` (сосед `audit-log.js`, electron не нужен — путь
передаётся): в `<userData>/agent.log` (JSONL, ротация 4 МБ → `agent.log.1`) ложится КАЖДАЯ пара
«вызов инструмента → результат» — время, инструмент, назначение, риск, откуда (ПК/телефон), исход,
длительность, размер вывода, обрезанные аргументы и обрезанный результат. Секретов нет: аргументы
через `toolPolicy.redact`, результат через `scrub`, значения переменных агента — по подстроке (список
берётся из `audit-log.js` — одна точка правды, туда его кладёт `agent-env.js`; добавлен только
геттер `audit.secrets()`). Результат хранится с ОБОИХ концов (как в части 54): у команд и запросов
важное — в конце, и head-only срез прятал бы именно ошибку.

**Точка записи — единственная.** `src/tool-registry.js` → `executeTool`: через неё проходят ВСЕ
вызовы (и параллельная пачка, и строгая очередь). Запись стоит ПОСЛЕ возврата назначения (строка не
увидит чужое окружение) и не бросает — сбой журнала глушит сам `record()`, прогон не рвётся. Модуль
необязателен: без него реестр работает как раньше. `agentLog` и `getRunOrigin` приезжают из `main.js`
(`agentLog.init(path.join(app.getPath("userData"), "agent.log"))`). К старым журналам это не
относится: `audit.log` продолжает писать только опасное.

**Проверки.** `test/smoke.test.js` — новая секция рядом с журналом опасного: пишется КАЖДЫЙ вызов
(и обычное чтение тоже), конец вывода сохраняется (ERESOLVE виден), секрет не попадает ни в
аргументы, ни в файл, выключение, битый путь и ротация. `npm test` — 0 падений (75 наборов;
smoke **536 → 537**). Полный живой прогон (настоящее приложение) — за владельцем.
