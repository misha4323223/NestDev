## Часть 48: настройки стирались на старте — «Отправить» не работала совсем

**Симптом.** Живой прогон окна (`npm run test:boot`) — **7 красных**: отправка не уходила,
кнопка «Стоп» не появлялась. Всё это от незакоммиченной работы над компоновкой чата, а не от
части 47: тот же прогон на коммите (проверено в отдельном worktree от `HEAD`) — чистый.

**Причина — не в чате, а в порядке загрузки.** Настройки лежат в `localStorage` и читаются
асинхронно, до них окно живёт на умолчаниях (`model: ""`). Новое «помним раскладку правой
рабочей области» (`sidePanelOpen` / `sidePanelTab`) восстанавливало панель **во время сборки
модулей** — до `ChatStore.wire()`, то есть до чтения настроек. А `openSidePanel` пишет
состояние через `persistSettings`, то есть **сохраняет целиком текущий объект настроек** — на
тот момент ещё умолчания. Итог: через миллисекунды после старта `model` снова становилась
пустой, и `sendMessage` молча выходил на проверке модели. Панель открывалась «как надо» —
просто попутно затирала всю сохранённую конфигурацию.

**Правка.** Восстановление раскладки ушло из времени сборки в уже существующий крючок
`afterLoad` (`app.js` → `SettingsPanel` рядом с `maybeAskFolders`), а сама функция
переименована в `restoreSidePanel` и вынесена в экспорт модуля: читать настройки можно только
после того, как они прочитаны. Телефонный случай сохранён — на узком окне панель сама не
открывается (иначе первый запуск закрыл бы собой чат), теперь проверка живёт внутри функции.

**Проверки.** `npm run test:boot` — снова «всё чисто» (0 падений), `npm test` — EXIT=0.
Сторож `test/agent-folders.test.js` печатает точную строку `afterLoad` и потому краснел на
новом вызове — обновлён на новую однострочную форму (стиль проекта: отложенное чтение
остаётся на той же строке, ради этого вызов и склеен в одну строку с `maybeAskFolders`).

**Почему это ловилось только живым прогоном.** Ни один модульный набор не читает
`localStorage` в этой последовательности: `afterLoad` там — заглушка. Порядок «сборка →
чтение настроек → первый ввод» воспроизводит только `scripts/live-boot.js`.

**Версия и набор.** Версия остаётся **1.5.216** (правка приехала в тот же заход), набор
пересобран: `node scripts/make-ota.js --unsigned` → **1.5.221**, 178 файлов, 159 JS проверены.
Сверено побайтово: все 178 файлов распакованного base64 совпали с диском, `side-panel.js`,
`app.js`, `yc-console.js`, `agent-tools-cloud.js` в наборе есть. Без подписи — ключа владельца
по-прежнему нет.
